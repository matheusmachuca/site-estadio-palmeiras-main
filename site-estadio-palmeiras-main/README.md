# Projeto Estádio do Palmeiras

Este projeto é um site informativo sobre o Estádio do Palmeiras, oferecendo informações sobre como chegar, se localizar dentro do estádio, além de detalhes sobre a sala de troféus, tours disponíveis e lojas.

## Estrutura do Projeto

- **index.html**: Página principal do site com cabeçalho e menu de navegação.
- **sobre.html**: Informações sobre a história e importância do Estádio do Palmeiras.
- **informacoes.html**: Dados gerais sobre o estádio, como capacidade e localização.
- **contato.html**: Informações de contato da administração do estádio.
- **css/style.css**: Estilos visuais do site.
- **js/script.js**: Scripts JavaScript para interatividade.
- **pages/como-chegar.html**: Informações sobre como chegar ao estádio, incluindo transporte público e estacionamento.
- **pages/entrada-e-localizacao.html**: Detalhes sobre a entrada e a localização dentro do estádio.
- **pages/sala-de-trofeus.html**: Informações sobre a sala de troféus e conquistas do clube.
- **pages/tours.html**: Descrição dos tours disponíveis, horários e preços.
- **pages/lojas.html**: Lista de lojas dentro do estádio e produtos disponíveis.

## Como Configurar

1. Clone o repositório ou faça o download dos arquivos.
2. Abra o arquivo `index.html` em um navegador para visualizar o site.
3. Para editar o estilo, modifique o arquivo `css/style.css`.
4. Para adicionar interatividade, edite o arquivo `js/script.js`.
